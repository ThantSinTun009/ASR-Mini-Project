# Recording report

ကျနော် AI Engineering Fundamentals အတန်းမှာ လုပ်ခဲ့တဲ့ Burmese ASR Mini Project တစ်ခုအတွက် အသံ recording ယူထားတဲ့ raw corpus ဖြစ်ပါတယ်။

## Recording Format

Recording တွေကိုတော့ 

```ရှေ့ 1.5 second.....အသံ......နောက် 1.5 second``` 

နဲ့ အသံသွင်းထားပါတယ်။

- အဆောင်မှာ နေရတဲ့ သူဖြစ်တာကြောင့် noise အနည်းဆုံးဖြစ်အောင် ညအချိန် **8:00 PM - 9:00 PM** အချိန်အတွင်း ယူထားသော အသံများဖြစ်ပါတယ်။

- အခုအသံများက **August 31, 2026 - September 2, 2026** ရက်နေ့အတွင်း ယူထားသော Recording များဖြစ်ပါတယ်။

## Recording Tools

Recording tool အနေနဲ့ ဆရာ Dr. Ye Kyaw Thu ရဲ့ Speech Training Recorder ကို အသုံးပြုထားပါတယ်။ Tool ရဲ့ အားသာချက်ကတော့ Kaldi နဲ့ ASR model တည်ဆောက်ဖို့ အတွက် လိုအပ်တဲ့ data format တွေကို recording ယူတဲ့အချိန်မှာပါ တစ်ခါတည်း ထုတ်ပေးတာဖြစ်ပါတယ်။ ဒါကြောင့် အချို့ preprocessing step တွေကို ပိုပြီး မြန်မြန်ဆန်ဆန် ပြုလုပ်လာနိုင်ပါတယ်။
